# Blessing.Kh Website & WebApp

ទីតាំងកូដ Website / WebApp ដាច់ដោយឡែកពី Telegram Bot ដើម (bot server)។

## រចនាសម្ព័ន្ធ Folder (Folder Structure)
- `index.html` : ទំព័រដើមនៃគេហទំព័រ (Main Website UI)
- `style.css` : ស្ទីល Design System & Responsive Styling
- `app.js` : Dynamic Interactive Features & Integration (Telegram WebApp SDK / API)
